# Event Manager

An Event Manager application with Google Calendar integration. Users can create, manage, and participate in events.

## Agent Rules Structure

Detailed rules for this project are organized in `.agents/rules/`:

- **[`project-overview.md`](.agents/rules/project-overview.md)** — Core features & requirements
- **[`tech-stack.md`](.agents/rules/tech-stack.md)** — Frontend, backend, database, and deployment tools
- **[`api-spec.md`](.agents/rules/api-spec.md)** — GraphQL entities, queries, and mutations
- **[`deployment.md`](.agents/rules/deployment.md)** — Docker, Nginx, CI/CD pipeline

Global coding conventions (coding style, TypeScript, git workflow) are defined in `~/.gemini/config/rules/` and apply automatically across all projects.
