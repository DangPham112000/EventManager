# Event Manager — Deployment Strategy

## Containerization
- Both Frontend and Backend are dockerized with individual `Dockerfile`s.
- `docker-compose.yml` orchestrates Frontend, Backend, Nginx, and MongoDB services.

## Frontend Serving
- Nginx serves the static files generated by Vite's production build.
- The Nginx configuration handles routing for the SPA (all routes → `index.html`).

## CI/CD Pipeline (GitHub Actions)

The deployment pipeline triggers on push to the `main` branch:

1. **Build** — Build Docker images for Frontend and Backend.
2. **Push** — Push images to a Docker registry (Docker Hub or GitHub Container Registry).
3. **Deploy** — SSH into the target VPS.
4. **Pull** — Pull the latest Docker images on the server.
5. **Restart** — Run `docker compose up -d` to restart services with the new images.
6. **Cleanup** — Execute `docker image prune -a -f` to remove old images and free disk space.

## Environment Configuration
- Use `.env` files for environment-specific configuration.
- Never commit secrets — use `.env.example` as a template.
- Production secrets should be managed via GitHub Actions secrets or server-side environment variables.
